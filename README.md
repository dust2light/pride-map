# MapDate

MapDate is a mobile-first dating map prototype.

## Current prototype

- Map-first discovery UI
- Demo nearby profiles
- Profile pins on the map
- Interest/like interaction
- Browser geolocation permission flow
- Mobile navigation shell

## Next build stages

1. Real map provider (OpenStreetMap/MapLibre)
2. Authentication and profiles
3. Privacy-safe approximate location
4. Matching and chat
5. Backend/database
6. Android packaging (PWA/Capacitor)
7. Moderation, reporting and safety controls

This repository is currently a prototype; no real user data is stored.
